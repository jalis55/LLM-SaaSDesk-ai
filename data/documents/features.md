# Product Features
FlowDesk is a fictional collaborative project-management SaaS.

## Projects and tasks
Members can create tasks, assign owners, set due dates, comment, and attach files. Free permits 2 active projects; Pro permits 100; Business has no fixed project-count limit, subject to fair use.

## Views
All plans include list and Kanban views. Timeline view is available on Pro and Business.

## Automation
Pro supports 20 active automation rules per workspace; Business supports 200. Free has no automation rules. Rules can trigger on task status changes or due-date reminders; they cannot send SMS.

## Exports
CSV task export is included in Pro and Business. Audit-log export is Business only. PDF task export is not currently supported.

## Mobile and offline
The mobile web interface is responsive. FlowDesk does not offer an offline mode or native desktop app in this fictional release.
